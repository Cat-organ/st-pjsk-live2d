一、这套东西怎么跑
--------------------------------------------------------
酒馆正则 → 加载器 → Cloudflare Pages 的 pjsk-game.html → GitHub raw 的素材

  页面   https://st-pjsk-live2d.pages.dev/pjsk-game.html   （Cloudflare Pages）
  素材   https://raw.githubusercontent.com/Cat-organ/st-pjsk-live2d/main/   （本仓库）
  正则   酒馆正则.json（导入酒馆即可，替换串里只有一条页面 URL）

楼层里只放三行加载脚本（$('body').load(页面URL)），页面本体不进酒馆——
上万行代码直接塞 iframe 会让酒馆明显卡顿。

本次改动（2026-11-26 16:49）
--------------------------------------------------------
1. 选项分支不再退回默认校服。分支是单独编译的，服装表以前从空开始，
   分支里没写服装的角色就用默认校服——看起来是"换回校服了"，还会因此
   多下一套本来不需要的模型。现在编译会把上一段的服装状态带进分支
   （compile 的 initialClothes），分支里继续穿运动服/便服。
2. 开演前先把这一场前几个模型备进缓存（遮罩显示「正在准备立绘 2/3」），
   备齐再开演，最多等 90 秒。原因是播放器给「角色上场」只留 12 秒
   （APPEAR_WAIT），素材在 github raw 上经常超时，超时那一句的立绘会被
   永久丢掉（控制台 model unavailable）。第二次打开有 HTTP 缓存，几秒开演。
   要关掉：PJSK_SETTINGS.warmup = false；要改备几个：warmupModels。

三、本地怎么测
--------------------------------------------------------
这个文件夹就是素材根目录，起个静态服务：

    cd /d K://st-pjsk-live2d
    python -m http.server 8933

然后打开 http://127.0.0.1:8933/regex/pjsk-game.html
（页面的 assetBase 指着 GitHub，本地测也会走外网；完全离线测要用
 game-renderer 的构建产物 --asset-base http://127.0.0.1:8931/pjsk-assets/）
